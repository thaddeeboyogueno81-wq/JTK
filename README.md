# JTK Résidence — site vitrine

Site multipage responsive pour JTK Résidence, Biyem Assi, Yaoundé.

Pages : accueil, appartements, services, galerie, présentation, réservation, contact.

Fonctionnalités : logo initiales JTK, preloader, transitions entre pages, animations au scroll, galerie/lightbox, formulaire WhatsApp, Google Maps et design mobile-first.

Les informations publiques utilisées pour le contenu ont été vérifiées sur des annonces de JTK Résidence. Les tarifs et disponibilités ne sont pas inventés et doivent être confirmés directement par la résidence.
